# Account screen

Account settings follow one reading column: password, email, then session details and logout.
Forms use shared panels and action spacing, with feedback immediately before their submit button.
Session details sit directly on the page background; a retrieval failure never blocks the forms.
Short section names identify the setting, while descriptions explain only what happens next.
