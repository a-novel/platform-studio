# Platform shell

The shell frames every Studio page with its navigation and its account controls. Each preview holds
one state fixed, so dismissing a menu leaves it as it was.

Expanded headers show the padded Studio wordmark, and the compact rail shows the icon. On mobile, the
wordmark and the menu control stay aligned between the closed header and the open menu.

People sign in on the account platform. "Log in" starts the request there and returns to the current
page, and "Register" opens the account platform's invitation request, the only way to get an
account. A signed-in visitor manages their account on the account platform too.
